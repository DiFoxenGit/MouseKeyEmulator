# 🖱️⌨️ MouseKeyEmulator

**Управляйте несколькими компьютерами с одного — по-настоящему, на уровне «железа».**

Один управляющий ПК транслирует ваши нажатия клавиатуры и движения/клики мыши
на **от 1 до 10** управляемых машин. Каждая управляемая машина получает ввод
через микроконтроллер **ESP32-S2**, воткнутый в её USB-порт, и видит обычную
USB-клавиатуру и мышь — не программу, а настоящее HID-устройство.

## ✨ Возможности

| | |
|---|---|
| 🎛️ **Мультиуправление** | Один компьютер → до 10 управляемых одновременно |
| ⌨️🖱️ **Клавиатура и мышь** | Нажатия, движение 1:1, клики, колесо, 5 кнопок, медиаклавиши |

## 🚀 Быстрый старт

### 1. Приложение (управляющий ПК, Windows 10/11)

1. Скачайте **`MouseKeyEmulator.exe`** из [**Releases**](../../releases/latest).
2. Запустите его (рекомендуется **от имени администратора** — нужно для
   перехвата и подавления ввода в эксклюзивном режиме).
3. Введите лицензионный ключ или нажмите **«Пробные 3 дня»**.

> Отдельная установка не требуется — это один самодостаточный файл.

### 2. Микроконтроллер (каждая управляемая машина)

Нужна плата **ESP32-S2** с нативным USB (например, ESP32-S2-Saola или
-S2-FN4R2). Прошивка — в папке [`firmware/`](firmware/). Кратко:

1. В Arduino IDE установите пакет плат **esp32** и библиотеку **Adafruit TinyUSB**.
2. `Tools → Board`: **ESP32S2 Dev Module**, `Tools → USB Mode`: **USB-OTG (TinyUSB)**.
3. Откройте [`firmware/MouseKeyEmulator/MouseKeyEmulator.ino`](firmware/MouseKeyEmulator/MouseKeyEmulator.ino) и прошейте.
4. В мониторе порта (115200) задайте сеть и общий ключ:
   ```
   ssid ИмяСети
   pass Пароль
   key  ваш_общий_ключ
   save
   connect
   ```

Подробности и распиновка — в [`firmware/README.md`](firmware/README.md).

### 3. Соединить

Плата и управляющий ПК должны быть в одной сети Wi-Fi. В приложении нажмите
**«Найти в сети»** — плата откликнется сама, останется включить её
переключателем и нажать **«Начать трансляцию»**.

## 🎮 Управление

| Действие | Клавиша |
|---|---|
| Старт / стоп трансляции | **F8** (настраивается) |
| Аварийная остановка (отпустить всё) | **Ctrl + Alt + Q** (настраивается) |
| Свернуть в трей | Кнопка «Свернуть» окна |

**Эксклюзивный режим** — ввод перестаёт доходить до управляющего ПК и уходит
только на платы, курсор фиксируется по центру экрана. Выход — F8 или аварийная
клавиша.

## 🔐 Лицензирование

Приложение работает по лицензии, привязанной к устройству. При первом запуске
введите ключ, полученный от продавца, — или возьмите **бесплатный пробный
период на 3 дня** (один раз на компьютер). Активация выполняется онлайн один
раз; далее приложение работает и без сети, периодически перепроверяя лицензию.

## ⚙️ Как это устроено

```
┌──────────────┐   Wi-Fi / UDP    ┌───────────┐   USB HID   ┌──────────────┐
│ Управляющий  │ ───────────────► │ ESP32-S2  │ ──────────► │ Управляемый  │
│ ПК (это      │  (1..10 плат)    │ «клав.+   │  (нативно)  │ компьютер    │
│  приложение) │                  │  мышь»)   │             └──────────────┘
└──────────────┘                  └───────────┘
```

- Ввод перехватывается на управляющем ПК нативными хуками Windows
  (`WH_KEYBOARD_LL` / `WH_MOUSE_LL`) и **Raw Input** — без ускорения указателя,
  один-в-один.
- Пакеты идут по UDP (порт `45123`) и защищены общим ключом (пакеты с чужим
  ключом плата игнорирует).
- Плата воспроизводит их как настоящие USB-HID-отчёты.

### Два режима

Переключатель **«Управление / Приём»** в шапке выбирает роль этого ПК.

## 🧩 Требования

- **Управляющий ПК:** Windows 10 / 11 (64-бит).
- **Платы:** ESP32-S2 с нативным USB, по одной на каждую управляемую машину.
- **Сеть:** общая сеть Wi-Fi/LAN между управляющим ПК и платами.

## ❓ Диагностика

| Симптом | Что проверить |
|---|---|
| Плата не находится | Тот же Wi-Fi; общий ключ в приложении = ключ в плате; порт 45123 не закрыт файрволом |
| «нет USB» у платы | Плата воткнута в управляемую машину; выбран режим USB-OTG (TinyUSB) |
| Ввод не подавляется локально | Запустите приложение от имени администратора |
| Мышь «дёргается» | Уменьшите частоту отправки или чувствительность в настройках |
