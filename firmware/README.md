# Прошивка ESP32-S2 — MouseKeyEmulator

Плата подключается в USB-порт управляемой машины и представляется ей обычной
USB-клавиатурой и мышью. По Wi-Fi она принимает пакеты от управляющего ПК
(приложение MouseKeyEmulator) и воспроизводит их как настоящие HID-отчёты.

> Программный режим без платы. Если ESP32 под рукой нет, управляемую машину
> можно перевести в режим «Приём» прямо в приложении — оно само вводит события.
> Плата нужна там, где ввод должен быть неотличим от аппаратного.

## Что понадобится
- Плата **ESP32-S2** с нативным USB (ESP32-S2-Saola, -S2-FN4R2, DevKitC и др.).
- **Arduino IDE** с пакетом плат **esp32** (Espressif).
- Библиотека **Adafruit TinyUSB** (Менеджер библиотек).

## Настройки Arduino IDE
| Параметр | Значение |
|---|---|
| Board | **ESP32S2 Dev Module** |
| USB Mode | **USB-OTG (TinyUSB)** |
| Upload Mode | Internal USB (или кнопкой BOOT) |
| USB CDC On Boot | Enabled (для монитора порта) |

## Прошивка
1. Откройте [`MouseKeyEmulator/MouseKeyEmulator.ino`](MouseKeyEmulator/MouseKeyEmulator.ino).
2. Нажмите **Upload** (при необходимости удерживайте BOOT для входа в режим прошивки).
3. Откройте **Serial Monitor** на 115200 бод.

## Первичная настройка (через Serial Monitor)
```
ssid ИмяВашейСети
pass ПарольWiFi
key  общий_ключ         # должен совпасть с полем «Общий ключ» в приложении
save
connect
```
После подключения плата напечатает свой IP-адрес. В приложении нажмите
**«Найти в сети»** — плата откликнется сама, либо добавьте IP вручную.

Сеть можно также прописать заранее в шапке `.ino` (`DEFAULT_WIFI_SSID` и т.д.).

## Маскировка под реальное устройство
Плата спуфит USB-идентификатор (VID/PID, строки производителя и продукта,
серийный номер из MAC) — по умолчанию под Logitech USB Receiver. Значения
меняются в шапке [`MouseKeyEmulator/usb_descriptors.h`](MouseKeyEmulator/usb_descriptors.h);
поставьте туда данные устройства, которое реально у вас есть, чтобы плата не
выделялась.

## Консольные команды
| Команда | Действие |
|---|---|
| `ssid <имя>` | Задать имя сети Wi-Fi |
| `pass <пароль>` | Задать пароль Wi-Fi |
| `key <ключ>` | Задать общий ключ |
| `save` | Сохранить во флеш |
| `connect` | Переподключиться к Wi-Fi |
| `status` | Показать состояние (Wi-Fi, IP, USB, счётчик пакетов) |
